# 📒 Les fiches de Romy

Une petite appli web pour transformer les photos de ses cours de Première en fiches de révision propres et imprimables, grâce à Claude.

1. Ouvre le site et, dans **⚙︎ Réglages**, colle une clé API Claude (elle reste seulement dans ton navigateur).
2. **＋ Nouvelle fiche** : choisis la matière, écris le nom du chapitre et ajoute les photos du cours.
3. **✨ Générer** : la fiche s'écrit en direct. Tu peux ensuite la modifier, l'imprimer ou l'enregistrer en PDF.

Les fiches sont enregistrées dans le navigateur. Pour les garder ailleurs, utilise **Réglages → Sauvegarder mes fiches**.
